# BASIC.FOOD — Мастер-план улучшений: путь к №1 в категории D2C pet-treats

> Дата аудита: 2026-07-21
> Проанализировано: `smith77788/basicfood` (ветка `main`, витрина + админка + 190 edge-функций + 340 миграций) и `smith77788/zoomarket` (ветка `main`) как источник переносимых наработок.

---

## 0. Резюме

BASIC.FOOD — технически зрелая платформа (React 18 + Vite + Supabase/Lovable Cloud + Capacitor + Telegram-бот + ACOS-автоматизация из ~80 автономных агентов). Фундамент сильный: атомарный чекаут через RPC, серверное ценообразование опта, продвинутый SEO (prerender, canonical-enforcement, programmatic landings, IndexNow), PWA, Sentry, CI.

Чтобы стать №1 в мире в категории, нужно закрыть 6 системных разрывов:

1. **Деньги теряются в чекауте** — онлайн-оплата фактически не подключена (только наложка и перевод на карту), хотя функции `monobank-create-invoice`/`monobank-webhook` уже написаны.
2. **Telegram-бот на поллинге** — медленно и дорого; в zoomarket уже есть webhook-архитектура.
3. **Поиск примитивный** — `ilike` по name/description, без опечаток, ранжирования и синонимов.
4. **Админка перегружена** — 65+ страниц и ~100 ACOS-панелей в одной навигации; работать в ней тяжело, RBAC грубый.
5. **Тестов почти нет** — 2 unit-файла и 2 e2e-спеки на 190 edge-функций и 340 миграций; e2e не гоняются в CI.
6. **Платформа заперта в Украине** — одна валюта, одна платёжка, одна служба доставки, i18n покрывает только часть строк (в `src/i18n/locales/*` лишь `common.json` и `home.json`).

Плюс из zoomarket нужно перенести целый блок готового кода: интеграцию с поставщиком DN-Trade, управление поставщиками/закупками, AI-парсер прайс-листов, обогащение изображений товаров, telegram-webhook и последнюю миграцию с защищёнными ролевыми RPC.

## 2. P0 — Критические исправления (недели 1–4)

Цель: перестать терять деньги и снять риски. Всё ниже — прямое увеличение выручки или устранение угроз.

### 2.1 Полноценная онлайн-оплата в чекауте
- Вывести Monobank Checkout (инвойс через существующий `monobank-create-invoice`) как первый способ оплаты в `Checkout.tsx`; после оплаты — webhook уже есть (`monobank-webhook`).
- Добавить Apple Pay / Google Pay через Monobank (поддерживается их API) — на мобильном трафике это +10–20% к конверсии оплаты.
- Порядок способов: Онлайн-карта/Pay → Наложка → Перевод. A/B-тест порядка через существующий механизм экспериментов.
- Статусная модель заказа: `awaiting_payment` → авто-отмена неоплаченных (функция `cancel-stale-orders` уже есть — связать).
- KPI: доля предоплаченных заказов, невыкупы наложки, конверсия шага оплаты.

### 2.2 Telegram-бот: переезд с поллинга на webhook (перенос из zoomarket)
- Портировать `telegram-webhook` + `telegram-setup-webhook`, перенести бизнес-логику из `telegram-poll` в обработчик webhook.
- Убрать `LEGACY_MANAGER_INVITE_CODE` из кода → Secrets + ротация; убрать mutable module-state.
- Ответ бота становится мгновенным; исчезают холостые cron-прогоны.

### 2.3 Безопасность ролей и аудита (перенос миграции zoomarket)
- Портировать `admin_grant_role`/`admin_revoke_role` RPC + `role_audit_log` + защиту последнего админа.
- Прогнать аудит RLS по всем новым таблицам за последние ~50 миграций (340 миграций — велика вероятность дрейфа политик).
- Ввести правило: каждый импорт/синк — с partial unique index по внешнему ID (паттерн `products_dntrade_product_id_key`).

### 2.4 Поиск, который продаёт
- Postgres FTS + `pg_trgm` (fuzzy/опечатки) + `unaccent`; материализованный tsvector по name+description+categories+синонимам (ua/ru/en варианты: «печінка/печень/liver»).
- RPC `search_products(query)` с ранжированием (ts_rank + продажи + наличие), подсветкой и «нулевой выдачей» с рекомендациями.
- Логировать поисковые запросы (уже есть `acos-search-intel` — замкнуть на реальные данные) → отчёт «искали, но не нашли» = план расширения ассортимента.

### 2.5 Минимальный страховочный контур качества
- Playwright e2e в CI (job с `bunx playwright test` против preview-сборки): смоук + полный happy-path чекаута + вход в админку.
- Vitest: юнит-тесты на критические RPC (create_order_with_items, промокоды, wholesale-цены) через локальный pg или контрактные фикстуры.
- Deno-тесты хотя бы для `_shared/*` (auth, ai-router) и топ-10 денежных функций (monobank-webhook — обязательно: подпись, идемпотентность, повторы).
